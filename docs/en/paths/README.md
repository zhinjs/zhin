# Learning Paths

zhin can be used for IM only, or all the way up to a full-featured Agent -- pick a path based on your goal.
Each path covers only the concepts you need; finish one, then switch.

| Path | Best For | Estimated Time | End Goal |
|------|----------|----------------|----------|
| [IM Bot Path](./im-bot.md) | I just want a command/notification bot, no AI | ~1 hour | Commands + adapter online |
| [AI Agent Path](./ai-agent.md) | I want an AI assistant that can chat and call tools | ~Half a day | AI chat + tools + memory |
| [Console Management Path](./console.md) | I want to manage bots / multiple accounts in a browser | ~1 hour | Console managing all endpoints |

The three paths are independent, but they all start from the same step:

```bash
npm create zhin-app my-bot -y
cd my-bot && pnpm dev
```
