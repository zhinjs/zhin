# Wiki Knowledge Base

This is a repository-owned Markdown copy of the [29-page Cubic Wiki](https://www.cubic.dev/wikis/zhinjs/zhin), captured on **2026-09-23**. Cubic generated it from [Zhin source commit `368db14`](https://github.com/zhinjs/zhin/commit/368db14caa4aa91311fb090f07bd792fe4b22fe7). Each article retains its original source references; [the manifest](/wiki/cubic/source.json) records its source URL and body hash. The pages are available in this site's navigation and local search.

::: warning Reference snapshot
These articles were generated by a third party and have **not** been verified page by page. They are useful for exploration, but code examples and operational advice can be wrong or outdated. The maintained [Zhin documentation](/en/getting-started/) and current source code take precedence. Seven pages with confirmed errors have correction notes above their original text.
:::

## Known corrections

| Snapshot topic | Current behavior | Maintained reference |
| --- | --- | --- |
| [Quick Start](./cubic/quickstart) | New projects require Node.js `>=22.12.0` and currently configure HTTP port `8068`; `8086` is the unconfigured runtime fallback. | [Getting Started](/en/getting-started/) |
| [Plugin Runtime](./cubic/plugin-runtime), [Commands](./cubic/commands) | Commands use `commands/**/index.ts`; Handlers use one named directory such as `handlers/message-receive/index.ts`. | [Convention Directories](/en/authoring/conventions) |
| [MCP](./cubic/mcp) | The optional Runtime Host registers Tools only when top-level `mcp:` is configured. `ai.mcpServers` is an Agent client setting. | [Runtime source](https://github.com/zhinjs/zhin/blob/main/packages/host/mcp/src/runtime.ts), [documentation correction](https://github.com/zhinjs/zhin/pull/684) |
| [Security & Sandbox](./cubic/security-sandbox) | `execApprovalMode` is `ask | auto | bypass`; Tool `requiresApproval` is `never | on-risk | once | always`. | [Agent configuration](/en/ai/), [Tool authoring](/en/authoring/agent-tools) |
| [Security Policy](./cubic/security-policy), [Production Deployment](./cubic/docker-prod) | The copied `8086` examples must be checked against the deployed `http.port`; new scaffolded projects use `8068`. | [Production Deployment](/en/operations/production) |

## Refreshing the snapshot

From the repository root, run `python3 scripts/import-cubic-wiki.py`. The importer downloads the public page, extracts its original Markdown, and updates the 29 articles and [source manifest](/wiki/cubic/source.json). It stops if the page format or article count changes, so a partial export cannot silently replace this copy. Review the diff and recheck correction notes before publishing a refresh.
