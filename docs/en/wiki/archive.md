# Cubic Wiki Archive

This archive preserves the [29-page Cubic Wiki](https://www.cubic.dev/wikis/zhinjs/zhin) and its [Chinese translation](/wiki/archive) for reference. It is a source snapshot, not a guide to current behavior.

For practical answers, start with the [knowledge index](/en/wiki/).

The English text was captured on **2026-09-23** from [Zhin source commit `368db14`](https://github.com/zhinjs/zhin/commit/368db14caa4aa91311fb090f07bd792fe4b22fe7).

Each article retains its source references; [the manifest](/wiki/cubic/source.json) records source URLs and body hashes.

::: warning Reference snapshot
These articles were generated by a third party and have **not** been verified page by page. They are useful for exploration, but code examples, source line anchors, and operational advice can be wrong or outdated. The maintained [Zhin documentation](/en/getting-started/) and current source code take precedence. Pages with confirmed errors have correction notes above their imported text; the importer also applies a small set of reviewed editorial fixes while recording the untouched upstream body hash.
:::

## Known corrections

| Snapshot topic | Current behavior | Maintained reference |

| [Quick Start](./cubic/quickstart) | New projects require Node.js `>=22.12.0` and currently configure HTTP port `8068`; `8086` is the unconfigured runtime fallback. | [Getting Started](/en/getting-started/) |
| [Plugin Runtime](./cubic/plugin-runtime), [Commands](./cubic/commands) | Commands use `commands/**/index.ts`; Handlers use one named directory such as `handlers/message-receive/index.ts`. | [Convention Directories](/en/authoring/conventions) |
| [MCP](./cubic/mcp) | The optional Runtime Host registers Tools only when top-level `mcp:` is configured. `ai.mcpServers` is an Agent client setting. | [Runtime source](https://github.com/zhinjs/zhin/blob/main/packages/host/mcp/src/runtime.ts), [documentation correction](https://github.com/zhinjs/zhin/pull/684) |
| [Security & Sandbox](./cubic/security-sandbox) | `execApprovalMode` is `ask | auto | bypass`; Tool `requiresApproval` is `never | on-risk | once | always`. | [Agent configuration](/en/ai/), [Tool authoring](/en/authoring/agent-tools) |
| [Configuration](./cubic/config) | `zhin migrate` does not transform `bots:` into `endpoints:`. | [Configuration](/en/configuration/) |
| [Agent orchestration](./cubic/ai-orchestration), [Security Policy](./cubic/security-policy) | Tool/Hook paths use named directories; `execSecurity` and `execApprovalMode` are separate settings. Built-in defaults are `deny` and `auto` unless project configuration overrides them. | [Convention Directories](/en/authoring/conventions), [Agent configuration](/en/ai/) |
| [Adapter Core](./cubic/adapters-core) | The snapshot conflates the scaffolded Endpoint example with `createEndpointLifecycle`; its incomplete inbound adapter example does not compile. | [Endpoint Lifecycle](/en/authoring/endpoint-lifecycle) |
| [Messaging](./cubic/messaging), [Satori](./cubic/satori) | Runtime `raw` is distinct from `segment.raw`; `wrapCardHtml` requires a background color. | [Middleware and Components](/en/authoring/middleware-components) |
| [Security Policy](./cubic/security-policy), [Production Deployment](./cubic/docker-prod) | The copied `8086` examples must be checked against the deployed `http.port`; new projects use `8068`. `pnpm daemon` and `pnpm stop` are legacy migration scripts. | [Production Deployment](/en/operations/production) |

## Refreshing the snapshot

From the repository root, run `python3 scripts/import-cubic-wiki.py`. The importer downloads the public page, extracts its Markdown, and applies the documented repairs.

It updates the 29 English articles and [source manifest](/wiki/cubic/source.json).

It stops if the page format or expected article IDs change, if a stale article is present, or if new raw HTML requires review. Run `python3 scripts/import-cubic-wiki.py --verify` to check the English snapshot.

Then update the Chinese translations and run `pnpm check:cubic-wiki-translations` before publishing a refresh. The importer does not overwrite translated pages.
