# 学习路径

不知道从哪读起？按你想做成的事选一条路。每条路只讲走通它需要的概念，走完再换下一条。

::: tip 运营 / 群主，不写代码？
不用走下面的开发路径。直接看 [运营与群管指南](../customer/index.md)：连上 Console、无代码改配置、群欢迎 / 公告 / 审批，以及什么时候该找开发者。
:::

| 我想… | 选这条路 | 大约用时 | 做完后你会有 |
|------|------|------|------|
| 做一个回命令、发通知的机器人，暂时不要 AI | [IM Bot 路径](./im-bot.md) | 1 小时 | 自定义命令 + 定时通知 + 一个真实平台在线 |
| 做一个能聊天、会调用工具的 AI 助手 | [AI Agent 路径](./ai-agent.md) | 半天 | 模型回复 + 自定义工具 + 记忆 |
| 在浏览器里查看和管理运行中的 Bot | [Console 管理路径](./console.md) | 1 小时 | 用 Console 收发消息、查执行过程、排查问题 |

三条路互相独立，但都从同一步开始——创建并启动一个项目：

```bash
npm create zhin-app my-bot -y
cd my-bot && pnpm dev
```

还没跑通这一步？先看 [快速开始](../getting-started/index.md)。
