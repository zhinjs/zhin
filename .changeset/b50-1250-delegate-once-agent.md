#1250 第 50 批：委派结果只给一次结论；新建模型服务不再叫 `service`。

- `delegate` 默认在本回合内最多等 20 秒：子 Agent 的结果按时回来，就直接出现在工具结果里，主模型据此回答一次，这条结果不会在之后再唤醒主 Agent（看图这类短任务走这条路）。传 `wait: false`（长任务）或等待超时，结果仍作为结果邮件稍后到达；工具结果要求模型期间不要自己回答被委派的部分、也不要猜结果。回合被停止时立即停止等待。
- 本次请求已经回复过用户之后，迟到的委派结果唤醒主 Agent 时，会先看到它之前回复的原文；结果没有新内容时模型输出 `[[no_reply]]`，什么都不发，结果只留在 trace；确有新内容才发一条，开头标「补充：」（英文会话为「Update: 」）。补充回合自身失败时仍按原样告知一次。
- `zhin ai account add` 新建服务时用驱动的显示名（如「Anthropic」）作服务名称，账号名称（`--name`）同时作为新建服务的名称；不再把计划别名 `service` 存成服务名称。
- 插话判断等日志里的服务名遇到泛化名称 `service` / `account` 时改用驱动名（如 `language:anthropic/claude-haiku-5-5`）。
