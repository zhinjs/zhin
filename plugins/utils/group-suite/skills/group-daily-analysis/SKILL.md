# 群日常分析

基于运行时统计数据分析群活跃度，并在需要时生成统一格式的群公告文本。

## 能力

- 统计群消息数量、参与人数、活跃时段分布
- 查询指定成员的今日、本周和累计消息数
- 生成群公告或通知文本
- 支持按群启用/禁用分析功能
- 定时任务自动生成分析报告推送到群内
- 通过聊天命令管理分析设置

`group_announce` 只生成文本，不直接发送消息；发送仍走统一消息链路。
