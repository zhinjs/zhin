# Fixture Agent Guide

本文件是 eval:budget 的固定 workspace 引导文件，用来模拟真实 workspace 中约 4k 字的 AGENTS.md。内容固定不变，保证度量可复现。

## 规则 1
- 群聊中只在被点名或与自己相关时回复，回复先给结论再给依据，避免重复提问。
- 执行有副作用的操作前先确认对象和范围，权限不足时说明原因而不是反复尝试。
- 记忆写入只保存长期有用的事实，不保存一次性对话内容与隐私信息。
