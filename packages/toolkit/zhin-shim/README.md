# zhin

从 4.0 起，npm 上的 `zhin` 是 [`@zhin.js/cli`](https://www.npmjs.com/package/@zhin.js/cli) 的别名：`npx zhin <命令>` 与 `npx @zhin.js/cli <命令>` 完全相同。

```bash
npx zhin new my-plugin
npx zhin --help
```

框架本体是 [`zhin.js`](https://www.npmjs.com/package/zhin.js)，文档见 <https://zhin.js.org>。

`zhin@3.x` 是早已停止维护的旧版框架包，不兼容当前的 zhin.js；仍锁在 `^3` 的项目不会自动升级到本包。

---

Since 4.0, `zhin` on npm is an alias of [`@zhin.js/cli`](https://www.npmjs.com/package/@zhin.js/cli): `npx zhin <command>` is the same as `npx @zhin.js/cli <command>`. The framework itself is [`zhin.js`](https://www.npmjs.com/package/zhin.js). `zhin@3.x` is the old, unmaintained framework package and is not compatible with the current zhin.js; projects pinned to `^3` are not upgraded automatically.
